# DataCamp Certificates Collection

Este repositório reúne meus certificados de conclusão de cursos realizados na plataforma **DataCamp**, organizados em três grandes categorias para facilitar a visualização e consulta.  
O objetivo é centralizar minha jornada de aprendizado em **Ciência de Dados, Inteligência Artificial e Automação**, mostrando tanto a diversidade quanto a profundidade dos conteúdos estudados.

## 📂 Estrutura

- **AI & Machine Learning**
  - Prompt Engineering
  - AI Agents
  - OpenAI API
  - Hugging Face
  - Vector Databases (Pinecone)
  - Ética em IA
  - Privacidade de Dados

- **Python & Data Science**
  - Fundamentos de Python (variáveis, funções, OOP, tratamento de erros)
  - NumPy & Pandas
  - Estatística e Probabilidade
  - Análise Exploratória de Dados (EDA)
  - Visualização de Dados (Seaborn, Matplotlib)
  - Regressão e Árvores de Decisão
  - PCA e Métodos de Agrupamento

- **Automation & Other Topics**
  - Automação de Fluxos de Trabalho com n8n
  - Conceitos de Comunicação de Dados
  - Webinars e conteúdos complementares

## 🎯 Objetivo

Este repositório serve como **portfólio educacional**, permitindo que recrutadores, colegas e interessados acompanhem minha evolução em Data Science e AI.  
Ele complementa minhas certificações formais (como EBAC e Oracle) e mostra meu compromisso contínuo com aprendizado e atualização.
